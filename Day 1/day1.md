 ## 1. Python in Simple Words

 Python is a **high-level, general-purpose programming language**.

 - **Created by:** Guido van Rossum
 - **First released:** 1991
 - **Name:** The name Python was not inspired by the snake. It was inspired by the British comedy show *Monty Python's Flying Circus*.

 Python was designed to make code easy to read and write. Its syntax looks quite similar to simple English.

 > Python is beginner-friendly, but it is also powerful enough to be used in systems such as Instagram, YouTube, and NASA.

 ---

 ## 2. Key Features of Python

 ### 👶 Easy to Learn

 - Semicolons are not required.
 - Curly braces are not used to define code blocks.
 - Type declarations are not required for basic code.
 - The syntax is clean and readable.

 ### 💪 Incredibly Powerful

 Python is used in many different fields:

 - Artificial Intelligence (AI)
 - Web Development
 - Data Science
 - Automation
 - Game Development
 - Cybersecurity

 ## 3. How Does Code Actually Run?

 Computers cannot directly understand human-readable code. Therefore, source code must be converted into a format that the computer can execute.

 There are two common approaches to code execution:

 1. **Compiled**
 2. **Interpreted**

 ---

 ## 4. Compiled Languages

 In a compiled language, the entire source code is converted into machine code before the program runs. This process is called **compiling**.

 ### Simple Example

 Think of it as translating an entire book from Hindi to English before giving it to someone. The translation is completed first, and then the translated book is used.

 ### Execution Flow

 ```text
 Source Code
      ↓
   Compiler
      ↓
  Machine Code
      ↓
  Program Runs
 ```

 ### Examples

 - C
 - C++
 - Rust
 - Go

 ---

 ## 5. Quick Recap

 - Python is a high-level, general-purpose language.
 - Python has simple and readable syntax.
 - Python is used in AI, web development, data science, and automation.
 - A computer processes source code before executing it.
 - Compiled languages convert the entire source code into machine code first.

 ## Key Takeaway
